# Team Task Manager

A full-stack web application for managing team projects and tasks with role-based access (Admin / Member).

## 🚀 Features
- JWT Authentication & Role-based Access
- Admin: Create projects, assign tasks
- Member: View tasks, mark done/undo
- Overdue detection with color-coded UI
- Responsive UI with Tailwind CSS

## 🛠 Tech Stack
- **Frontend:** React + Vite, Tailwind CSS
- **Backend:** Node.js, Express.js, MongoDB Atlas
- **Auth:** JWT
- **Deployment:** Render (Backend), GitHub Pages/Netlify (Frontend)
